# Bitget Agent Hub Research Context

Snapshot date: 2026-09-27

Purpose: reusable research context for product discovery, hackathon ideation, SDK extension work, and Codex sessions involving Bitget Agent Hub / Bitget-AI.

This folder intentionally separates three things that currently drift from each other:

1. Public Bitget documentation and product pages.
2. Public GitHub `main` source under the Bitget-AI organization.
3. Published npm package/runtime behavior, which is newer than some GitHub `main` files.

Start with `01_AI_CONTEXT.md`, then use the deeper files when needed.

## Files

- `01_AI_CONTEXT.md` - compact context to paste into Codex.
- `02_ORG_REPO_MAP.md` - Bitget-AI public repository map.
- `03_ARCHITECTURE.md` - execution architecture and trust boundaries.
- `04_SDK_CAPABILITIES.md` - SDK source-level capability map.
- `05_EXISTING_PROJECTS.md` - known community/integration patterns and crowded areas.
- `06_GAP_MAP.md` - underbuilt product/infrastructure hypotheses.
- `07_VERSION_DRIFT.md` - documentation, GitHub, npm mismatches to watch.
- `08_RESEARCH_NEXT.md` - next investigation steps before selecting a build.
- `SOURCES.md` - URLs and source paths.
- `snapshot.json` - machine-readable facts from the research pass.
